# 2C 社交产品行业模块

## 行业特征

- 用户为个人，追求归属感/表达/效率/娱乐
- 核心竞争力来自用户之间的互动——你的价值 = 其他用户的存在
- 冷启动是最大的死亡谷（鸡生蛋蛋生鸡）
- 基模威胁：Agent 可以替代部分社交角色（客服、主持人、搭子），大厂社交网络天然具有碾压优势
- 大科技竞争对手不一定是"另一家创业公司"，而可能是微信/抖音在现有产品里加一个 Agent

## 评分维度（7 维度 × 加权）

### 正向逃逸燃料（满分 70）

#### 1. 网络效应密度（权重 ×3.0，满分 30）

**核心判断**：每多一个用户，其他用户的价值是否显著提升？这是社交产品最核心的逃逸燃料。

- **9-10 分**：强网络效应——用户越多社区越活跃→更多用户→更强锁定。已有规模化用户基础，形成"离开就失去社交资产"的锁定
- **7-8 分**：有明显网络效应且正在加速，但尚未形成不可逆的锁定
- **4-6 分**：有一定网络效应但密度不够，用户间互动稀疏
- **1-3 分**：无明显网络效应，或未验证

**子维度判断**：
- **双边还是单边**：群聊/社区是多对多（强网络效应），工具型社交是一对多（弱）
- **同边网络效应**：用户越多，单个用户越受益（如微信群越多→你能进的群越多）
- **跨边网络效应**：创作者越多→消费者越多→创作者更多（如小红书/知乎）

**关键追问**：
- "如果今天你的服务关闭，用户失去了什么不可替代的社交资产？"
- "最后一个离开的用户和第一个进来的用户，体验差距有多大？"
- "用户是来用工具的还是来见人的？——工具可以换，人换不了"

#### 2. UGC/行为数据飞轮（权重 ×2.0，满分 20）

**核心判断**：用户行为是否产生不可从公开互联网复制的数据/内容资产？

- **9-10 分**：用户生成内容（UGC）+ 行为数据形成闭环飞轮，数据越用越好，新用户体验越好，且无法从其他渠道获取
- **7-8 分**：有明显的 UGC 积累，但推荐/匹配能力尚未形成飞轮
- **4-6 分**：有 UGC 但质量或独特性不足，可被其他平台内容替代
- **1-3 分**：无 UGC 或行为数据积累

**社交产品的数据飞轮典型路径**：
- 用户互动 → 关系图谱 → 更好匹配 → 更多互动
- 用户发内容 → 内容池 → 更好推荐 → 更多内容
- 社区行为 → Agent 学习社区规范 → 更好治理 → 更强社区

**关键追问**：
- "你的平台上有多少内容是全网独家的？"
- "用户的互动数据能否训练出比通用模型更好的社交匹配算法？"

#### 3. 社区文化壁垒（权重 ×1.5，满分 15）

**核心判断**：是否形成了独特的社区文化/身份认同/黑话体系？大厂能不能用钱砸出一个一模一样的社区氛围？

- **9-10 分**：已形成高度独特的社区文化和身份认同（如 B 站弹幕文化、豆瓣小组氛围、即刻社区规范），文化是不可复制的
- **7-8 分**：社区文化正在形成，有早期核心用户群的强认同
- **4-6 分**：用户之间有互动但未形成可辨识的文化标签
- **1-3 分**：无社区文化，纯工具型

**关键洞察**：文化是社交产品最慢的变量——大厂可以复制功能、买量、砸钱，但复制不了一种文化。这是社交产品对抗巨头的终极护城河。

**关键追问**：
- "你的用户之间有专属的'黑话'、梗、仪式吗？"
- "如果用一句话描述你的社区氛围，你的核心用户会说什么？"
- "微信做一个功能一样的群聊，你的社区文化能留住多少人？"

#### 4. 冷启动能力（权重 ×1.5，满分 15）

**核心判断**：有没有可验证的低成本获客引擎？鸡生蛋问题怎么解？

- **9-10 分**：有成熟的可复制冷启动方法论（如 Jenni.ai 的短视频矩阵），已验证的获客成本持续下降
- **7-8 分**：有一定冷启动能力但未完全规模化，部分渠道验证有效
- **4-6 分**：有冷启动策略但未验证，获客成本不确定
- **1-3 分**：无明确冷启动策略，或策略完全依赖资金投放

**关键追问**：
- "第一个 1000 个用户怎么来？验证过吗？"
- "有没有不依赖投放的自然增长？占比多少？"

### 负向风险扣分（满分 -35）

#### 5. 巨头替代风险（权重 ×-2.0，扣分上限 -20）

**核心判断**：微信/抖音/Meta 在现有产品里加一个 Agent/功能，你的用户留多少？这是社交产品最大的风险维度。

- **9-10 分（极高风险）**：产品核心功能是巨头现有社交网络的"功能补丁"，巨头上线即死亡
- **7-8 分（高风险）**：有一定创新但巨头 6 个月内可复制核心功能
- **4-6 分（中风险）**：定位在巨头盲区，但巨头如果认真做会形成威胁
- **1-3 分（低风险）**：巨头短期不会进入（市场太小/文化壁垒太高/与巨头核心利益冲突）

**社交产品的巨头替代逻辑与 2B 不同**：
- 2B 的替代障碍 → 工作流深度、合规、合约
- 社交的替代障碍 → 社交资产（关系链、身份、记忆）、社区文化、网络效应

**关键追问**：
- "微信给你的群聊加一个有记忆、能管事、会聊天的 Agent，用户为什么还要来你的 App？"
- "你的用户之间的关系链，是只存在于你这里，还是同时存在于微信/QQ/抖音？"

#### 6. 网络冷启动死亡谷（权重 ×-1.0，扣分上限 -10）

**核心判断**：鸡生蛋问题有没有可信的解决方案？社交产品最大的失败原因就是冷启动失败。

- **8-10 分**：无已验证的冷启动方案，或方案依赖"等用户自然增长"
- **5-7 分**：有冷启动策略但高度不确定，需要大量资金或运气
- **1-4 分**：已部分验证冷启动能力，有可复制的模式

**社交冷启动的危险信号**：
- "我们先做一个工具，然后加上社交"——工具转社交成功率极低
- "群聊 500 人约等于死群"——大群无治理能力 → 沉默 → 死亡
- 依赖 KOL/大 V 拉新 → 他们一走社区就死

#### 7. 变现路径风险（权重 ×-0.5，扣分上限 -5）

**核心判断**：变现模型是否与社交体验冲突？是否过度依赖广告而牺牲用户体验？

- **5 分**：变现与核心体验严重冲突（如广告破坏社区氛围），或完全无变现路径
- **3-4 分**：有变现计划但未验证，或模型存在明显矛盾
- **1-2 分**：有可行的变现路径，与社交体验基本兼容

**社交产品变现陷阱**：
- 过早变现 → 杀死社区 → 杀死产品
- 过度依赖广告 → 内容质量下降 → 用户流失
- 纯订阅制社交 → 付费墙阻碍网络效应

## 行业特定关键追问

1. "第一个 1000 个用户是谁，为什么他们会来，为什么不会走？"
2. "用户之间的关系链，是只存在于你这里，还是同时存在于微信？"
3. "你的社区有没有出现'自发秩序'——用户自己定的规矩、发明的梗、形成的亚文化？"
4. "如果微信/抖音在三个月内做了一样的事，你还有什么？"
5. "你的社区里有没有'留下来不是因为功能而是因为人'的用户？比例多少？"
